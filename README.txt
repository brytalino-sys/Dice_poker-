Покер на костях — веб-версия для хостинга
=========================================

Эти файлы — готовая игра. Её можно положить на любой хостинг статических
сайтов с HTTPS (например, GitHub Pages) и открыть по ссылке в браузере
или как мини-приложение Telegram (адрес указывается в @BotFather → /newapp).

Без сервера работают карьера, партии с ботом и игра вдвоём.
Для игры по сети нужен сервер игры с HTTPS — впишите его адрес в config.js:
  server: 'https://dice.example.com:8443',
Там же — ссылка на мини-приложение для приглашений:
  telegramLink: 'https://t.me/ИмяБота/play',

Подробная инструкция — README.md в архиве DicePoker-source.zip.
